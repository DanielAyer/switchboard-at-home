switchboard-at-home & stt-tts Architecture

A two-repository local voice fabric built around clean separation of concerns: switchboard-at-home (SaH) owns multi-session Zenoh routing, per-doublet actor threads, the 4-state half-duplex button machine, 300 ms paced audio playback, and the Kotlin Android handset, while stt-tts stays a pure, GPU-free CPU speech converter (Core) plus a zero-dependency ECDSA P-256 OpenSSL private CA.

Trust Boundaries: Built in SaH vs. stt-tts Only

Directly audited from protocol.py, zenoh_session.py, security.py, llm_http.py, and pki.py
A · Doublet Write-Lock 24-byte CSPRNG app_token & terminal_token in Zenoh attachments gate publishes; listeners stay open. Requires TLS on router for confidentiality. Built in SaH.
B · Zenoh mTLS (optional) & Router ACLs SaH can turn on client mTLS through zenoh.tls.*. The router ACL comes from stt-tts security acl, which only covers the old voice/* keys; with its default-deny it would block sah/**, so it is not usable with SaH yet.
C · Fail-Closed Input Gate (stt-tts only) security.enforce() blocks startup if llm.enabled=true without enabled input allowlist (cert:<CN>) and Zenoh TLS when Zenoh inputs are active. SaH never calls it.
D · Remote LLM HTTPS (planned) llm_http.check_url() permits plain http:// strictly on loopback; non-loopback GPU hosts require HTTPS verified against system CAs or private llm.ca_file. The POST itself is still a stub, and SaH has no LLM bridge yet.
E · Private CA Root (stt-tts tooling) ~/.local/share/stt-tts/pki/ca.key (ECDSA P-256, 0600) is the root of trust for the household mesh; API keys live in OS keyring or 0600 secrets.json.

04 · Zero-Dependency OpenSSL PKI & mTLS

Private ECDSA P-256 Root CA, Mutual TLS & Fail-Closed Gating

stt_tts/pki.py mints an entire household X.509 trust hierarchy by invoking the system openssl CLI directly—zero Python crypto wheels—and pairs it with Zenoh mTLS, X.509 CN router ACLs, fail-closed security.enforce(), and an OS keyring → 0600 secrets.json credential cascade. All of this lives in stt-tts. SaH itself only reads zenoh.tls.* to open a client mTLS session; it does not call enforce(), the generated ACL only covers voice/* keys, and the LLM POST in llm_http.py is a stub.

Verified Platform Note · Linux OpenSSL 3.x vs. macOS Stock LibreSSL 3.3.6

On Target 1 (Linux OpenSSL 3.x), every command in stt_tts/pki.py works cleanly. On stock macOS /usr/bin/openssl (LibreSSL 3.3.6), pki.init_ca() and pki.issue() succeed, but pki.describe() (openssl x509 -in cert.pem -noout -enddate -ext extendedKeyUsage,subjectAltName) fails with unknown option -ext, affecting stt-tts certs list and post-issue summaries. Workaround: put Homebrew openssl@3 ahead of /usr/bin on PATH.

Architectural Strengths6 Verified

Strict Separation of Concerns

SpeechBackend (2 capabilities: streaming STT + per-sentence TTS) isolates Zenoh routing, session actors, and button state (switchboard-at-home) from ML engines (stt_tts/core.py).

GPU-Free Voice Server

Moonshine STT/TTS and Kokoro-82M ONNX run entirely on a modest 4-core AVX2 CPU (reference rig: nidavellir i7-6700T), leaving 100% of GPU VRAM on ravensnest free for LLMs.

0 ms Local Flush & Honest Barge-In

300 ms paced server lead + ~200 ms Android AudioTrack + pre-network local speaker.flush() + cancel.wait() make barge-in instantaneous, while interrupted.spoken_text keeps LLM memory honest.

Zero-Dup Multi-Venv Packaging

install.sh writes a 2-line stt_tts_link.pth into SaH's venv, importing stt_tts and heavy ONNX/Moonshine packages read-only with zero duplicated weights or Zenoh leakage into stt-tts.

Clean Actor Concurrency & Key Hygiene

One DoubletRunner thread per doublet isolates sessions, shared _TRANSCRIBERS + RLock prevents N× RAM bloat, app_slug() + RESERVED + monotonic Namer stop wildcard injection and stale-ID races, and liveliness drops release or close a doublet at once, while a 1 s _sweep closes apps that never show up within 30 s.

Zero-Dep Operational Safety

Stdlib transactional installer with manifest rollback, pinned SHA-256 atomic Kokoro downloads, zero-dep OpenSSL P-256 CA, and fail-closed security.enforce() in stt-tts (not wired into SaH yet).

Honest Trade-Offs & Current Limitations8 Audited in Code

Cleartext Tokens & Android Missing TLS

app_token and terminal_token travel unencrypted in Zenoh attachments on tcp/; Android ZenohLink.kt currently supports plain tcp/ only (TLS and planned server_public_key E2EE are not yet wired).

Open-to-Listen & Legacy ACL Scope

Anyone connected to zenohd can subscribe to audio/in, audio/out, text/in, and text/out until router ACLs or E2EE (Sealer, currently NotImplementedError) land; stt-tts security acl still targets legacy voice/* keys.

Serialized Global TTS & Single Static Voice

All doublets serialize TTS synthesis on VoiceService.tts_lock (one sentence at a time), and Core loads one static configured voice (per-call voice override raises ValueError).

Sentence-Granular Interrupt Ledger

DoubletRunner._play appends each sentence to self.spoken only after sending its chunks (not per word/frame), so interrupting mid-sentence can under-report an unfinished first sentence or include ~300 ms buffered tail.

In-Memory Ephemeral State (Single Node)

Open doublets, bearer tokens, and Namer counters live only in sah serve RAM; restarting sah serve resets counters to <slug>/1 and requires apps and terminals to re-register.

Residual Legacy Code & Stubs in stt-tts

Single-pipeline pipeline.py, zenoh_adapter.py, llm_http.py:send (POST still stubbed), Sealer (stub), and archival bak/ directories + stt-tts.zip still reside in stt-tts.

macOS LibreSSL 3.3.6 -ext Gap

Stock macOS /usr/bin/openssl (LibreSSL 3.3.6) rejects openssl x509 -ext in pki.describe(), breaking stt-tts certs list and post-issue summaries (Linux OpenSSL 3.x works cleanly; macOS needs Homebrew openssl@3 on PATH).

Android Foreground-Only & Legacy Package

Android keeps the screen awake (keepScreenOn) rather than running a microphone foreground service, lacks hardware button wiring (TerminalViewModel.press() is ready), and retains pre-split package io.github.danielayer.stttts.terminal.
